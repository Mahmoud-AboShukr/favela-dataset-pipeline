## Current pilot note (Brasília)
In the Brasília pilot, we produced an AOI-wide GHSL-derived settlement mask (`brasilia_settlement_mask.tif`) by thresholding GHSL built-up values and applying morphological cleanup. Visual QC indicates remaining false negatives in some settlement areas, suggesting that either (i) the selected threshold is too strict for the intended definition of settlement extent, (ii) GHSL built-up at 10 m is patchy for certain textures, or (iii) some missed regions correspond to nodata. We will validate using point value probes and a threshold sweep before using the settlement mask as a constraint for favela label refinement.
